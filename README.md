# مكتبة الأصيل — تطبيق حقيقي

منصة كتب عربية بـ Next.js (App Router) وقاعدة بيانات SQLite حقيقية (عبر `node:sqlite` المدمجة في Node.js، بدون أي خدمة خارجية). تحتوي على ٥٠ كتابًا حقيقيًا، استبيان ذوق قرائي، توصيات مبنية على درجة مطابقة فعلية، ومكتبة شخصية (حالة القراءة، التقدم، المفضلة، التقييمات) — كل ذلك محفوظ بشكل دائم لكل زائر عبر كوكيز مجهولة (بدون تسجيل دخول).

## التشغيل

```bash
npm install       # أول مرة فقط
npm run seed      # تعبئة قاعدة البيانات بالخمسين كتابًا (يُنشئ data/app.db)
npm run dev       # يشغّل على http://localhost:3000
```

## البنية

- `src/lib/data.js` — أسماء الأنواع، أسئلة الاستبيان، أنماط القرّاء (بيانات ثابتة).
- `src/lib/db.js` + `src/lib/repo.js` — قاعدة بيانات SQLite حقيقية وطبقة الوصول لها.
- `src/lib/scoring.js` + `src/lib/recommend.js` — محرك التخصيص: يحوّل إجابات الاستبيان إلى ملف ذوق، ويسجّل ملاءمة كل كتاب.
- `src/lib/reader.js` — هوية قارئ مجهولة عبر كوكيز (بدون كلمة مرور).
- `src/app/api/*` — نقاط API (الكتب، الاستبيان، التوصيات، المكتبة، التقييمات، اكتشف لي كتابًا).
- `src/app/*` — الموقع المستقل الكامل (الرئيسية، الاستبيان، النتيجة، التوصيات، تفاصيل الكتاب، مكتبتي، اكتشف كتابًا).

## الودجت (الإضافة القابلة للتضمين في مواقع أخرى)

الميزة نفسها متاحة أيضًا كإضافة (Widget) تُدمج داخل أي موقع مكتبة رقمية منشور مسبقًا، بدون أن يغادر الزائر الصفحة الأصلية:

- `public/widget.js` — سكربت مستقل بدون تبعيات. يُضاف بسطر واحد في أي موقع:
  ```html
  <script src="https://<app-origin>/widget.js"></script>
  ```
  يرسم تبويبًا عائمًا على حافة الشاشة (يمين)، وعند الضغط عليه يفتح لوحة منزلقة تحتوي على iframe معزول تمامًا عن الموقع المضيف (لا تعارض تنسيقات CSS ولا جافاسكربت في أي الاتجاهين).
- `src/app/embed/*` — نسخة مصغّرة من نفس التجربة (اكتشف ذوقي، اكتشف كتابًا، توصياتي، مكتبتي، تفاصيل كتاب) مصمَّمة لعرض ضيق (~460px)، هي ما يُحمَّل داخل iframe اللوحة عبر المسار `/embed`.
- `src/app/demo` — صفحة تُحاكي موقع مكتبة رقمية آخر منشورًا مسبقًا («مكتبة النور»، بتصميم مختلف تمامًا عن هوية التطبيق)، وتُضيف الودجت بنفس الطريقة التي يضيفها أي موقع خارجي حقيقي — لتجربة الدمج الفعلي بنفسك على `/demo`.

الودجت واللوحة يستخدمان نفس قاعدة البيانات ونفس محرك التخصيص تمامًا مثل الموقع المستقل — الهوية القرائية والتوصيات ومكتبتك الشخصية محفوظة فعليًا، سواء دخلت من الموقع الكامل أو من داخل اللوحة المضمَّنة.

**ملاحظة تقنية للنشر الحقيقي عبر نطاقات مختلفة:** التجربة على `/demo` تعمل بسلاسة تامة لأن كل شيء على نفس النطاق (Same-Origin)، فكوكيز القارئ المجهول تُحفظ وتُقرأ بلا مشاكل. عند نشر الودجت فعليًا على نطاق موقع مكتبة **مختلف** عن نطاق هذا التطبيق، ستصبح كوكيز الـ iframe كوكيز طرف ثالث (Third-party cookies)، وبعض المتصفحات (Safari، وتدريجيًا Chrome) تُقيّدها أو تُقسّمها. الحل عند الوصول لتلك المرحلة هو تخزين هوية القارئ في `localStorage` داخل الـ iframe نفسه (نفس نطاق التطبيق دائمًا من منظور الـ iframe) بدل الاعتماد على كوكيز — تغيير محصور في `src/lib/reader.js` فقط، دون أي تعديل على منطق التخصيص أو الواجهات.

## ملاحظة

قاعدة البيانات ملف محلي في `data/app.db` (غير مُتتبَّع في git). لحذف كل البيانات والبدء من جديد: احذف المجلد `data/` ثم شغّل `npm run seed` مجددًا.
